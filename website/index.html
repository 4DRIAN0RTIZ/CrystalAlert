Install like a utility, not a framework.

Drop in the CDN build or copy the dist files. No bundler required.

CDN 
<!-- CSS -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/4DRIAN0RTIZ/CrystalAlert/dist/crystal-alert.min.css">

<!-- JS -->
<script src="https://cdn.jsdelivr.net/gh/4DRIAN0RTIZ/CrystalAlert/dist/crystal-alert.min.js"></script>

<!-- Optional: Dark theme -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/4DRIAN0RTIZ/CrystalAlert/dist/themes/dark.min.css">
Download 
# Clone the repository
git clone https://github.com/4DRIAN0RTIZ/CrystalAlert.git

# Copy dist files (minified)
cp CrystalAlert/dist/crystal-alert.min.js your-project/
cp CrystalAlert/dist/crystal-alert.min.css your-project/

# Copy themes (optional)
cp -r CrystalAlert/dist/themes your-project/

Crystal.fire(options)

Display a modal alert dialog. Returns a Promise. Calls made while another modal is open are queued.

title
The alert title text
text
Plain text content
html
HTML content (overrides text)
icon
success | error | warning | info
iconHtml
Custom HTML for icon
showCloseButton
Show X button in corner
showCancelButton
Show cancel button
preConfirm
Async function before confirm
timer / timerProgressBar
Auto-close in ms, with an optional progress bar
onOpen / onClose
Lifecycle callbacks

Crystal.toast(options)

Display a non-blocking toast notification.

title
The toast title text
text / html
Content (plain or HTML)
icon / iconHtml
Built-in or custom icon
duration
Auto-dismiss ms (0 = persistent)
position
top-right | top-left | bottom-right | bottom-left

Crystal.prompt(title, options)

Ask for a value. Resolves with the input value, or a falsy result when dismissed.

input
email | number | text | select
inputPlaceholder
Placeholder for the field
inputValidator
Return a message to block confirmation, or an empty string
inputOptions
Options for a select (strings or { value, label })
const email = await Crystal.prompt('Subscribe', {
  input: 'email',
  inputPlaceholder: 'you@example.com',
  inputValidator: (v) => v.includes('@') ? '' : 'Enter a valid email.'
});

Crystal.setTheme(name)

Load a theme CSS file. Returns a Promise that resolves when it is loaded.

name
default | dark | minimal | custom
returns
Promise that resolves when loaded
// Load dark theme
await Crystal.setTheme('dark');

// Custom theme path
Crystal.setThemePath('/css/themes/');
await Crystal.setTheme('brand');
